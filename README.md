# CYX Quant

加密货币量化交易软件（前端终端）。

## 功能

- 实时行情与 K 线（OKX 公开接口）
- 技术指标：MA / EMA / RSI / MACD / 布林带
- 四种量化策略信号：双均线、RSI 回归、MACD 动量、布林突破
- 本地模拟交易（起始 $100,000）
- 策略历史回测与权益曲线

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

> 本项目为研究/模拟用途，不构成投资建议，也不会连接真实交易所账户下单。
